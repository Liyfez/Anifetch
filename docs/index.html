CLI Commands Cheat Sheet

Quick copy-paste commands for everyday use.

anifetch <username>
Fetch full profile and export to JSON
anifetch <username> --completed --json
Export only completed anime to JSON
anifetch <username> --all --csv
Export entire anime list to CSV spreadsheet
anifetch <username> --dropped --txt
Export dropped anime to plain-text report
anifetch <username> -f all
Export to all 4 formats (JSON, CSV, TXT, MD)
anifetch <username> --min-score 85
Filter anime by minimum score (85+ or 8.5+)
anifetch --demo
Test extraction with sample offline profile
